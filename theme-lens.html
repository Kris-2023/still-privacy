Still Theme Lens 隐私政策

版本 0.4.0 · 更新日期：2026-09-30
发布者：Kris-2023

用途与本地处理

Still Theme Lens 帮助用户识别当前网页中的 Shopify、WordPress、WooCommerce 平台特征与主题线索。你点击扩展后，它读取当前顶层页面的地址、公开主题声明、资源路径、平台标记和 Shopify 店铺域名，在本机与随扩展提供的主题库进行比较。不会自动遍历其他标签页或读取浏览器历史数据库。

读取与保存的信息

为完成检测，扩展在内存中检查页面内嵌脚本中的特定公开主题配置、meta/link 元素、资源地址及相关页面类名。只返回用于检测的字段，不上传或保存整页 HTML/脚本。页面 URL 和资源地址移除查询参数及片段。检测结果包含当前页面地址、店铺域名、平台、主题名称/ID/版本声明、证据和时间。

只有点击“保存”，结果才写入 Chrome 本机扩展存储；最多保留 50 个页面，同一地址重新保存会替换旧结果，超过上限淘汰最早记录。语言偏好也保存在本机；清空历史不会重置语言，可选择“自动”恢复跟随浏览器。不使用云同步。你可以清空本地历史；卸载扩展也会移除扩展存储。JSON 导出文件和复制到剪贴板的文本由你自行管理，不会随卸载自动删除。

不收集或传输的内容

不使用 Cookie、登录凭据、Shopify 后台授权、订单、客户信息、付款信息或用户输入的表单内容。没有分析追踪、广告、遥测或远程脚本。检测功能不把页面内容或结果发送给发布者或第三方服务器，数据不出售，不用于广告、信用或借贷判断。

外部链接与主动分享

点击官方主题或支持链接时，浏览器会访问相应第三方网站，适用该网站政策。复制或导出由用户主动发起。若你在支持 Issues 中提交截图、日志或问题，GitHub 会按其政策处理你主动提交的信息；请勿附带密码、客户信息或访问令牌。

权限说明

activeTab：用户点击后临时读取当前页面。scripting：在隔离环境执行只读采集。storage：保存语言偏好及用户主动选择的本地检测历史。没有所有网站的持久 host_permissions，不修改网页内容。

安全与检测边界

没有把敏感信息发送到服务器的设计；本地数据依赖设备和 Chrome 配置的保护，不额外承诺独立加密。公开元数据可能被修改，第三方配置可能过期。ID 匹配、第三方佐证、页面声明和无法识别分别标记。结果不证明主题授权、未修改状态或完整源码。

Limited Use

Still Theme Lens 对用户数据的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。数据只用于明确展示的平台与主题检测、复制、导出和用户选择的本地历史功能，不用于无关目的。

联系与变更

隐私与支持：github.com/Kris-2023/still-privacy/issues。数据处理方式发生实质变化时，会随扩展版本更新本政策。

本扩展不是 Shopify、WordPress、WooCommerce、Google 或 Chrome 的官方产品；名称仅用于说明兼容平台，不代表其认可。

Still Theme Lens Privacy Policy

Last updated: September 30, 2026
Publisher: Kris-2023

Purpose and information processed

Still Theme Lens identifies public Shopify, WordPress and WooCommerce platform signals and theme information on the current page. When you open the extension or request another scan, it reads the top-level page URL, selected public theme configurations in inline scripts, metadata, resource URLs, relevant page classes and the Shopify store domain. Processing takes place on your device using a bundled theme catalogue. It does not scan other tabs automatically or read Chrome's browsing history database.

Page and resource URLs are stripped of query parameters and fragments. Results may include the page URL, shop domain, platform, theme names, IDs, declared versions, evidence and detection time. The extension does not save or upload full page HTML or scripts.

Local storage and your controls

Detection results are saved to chrome.storage.local only when you choose Save. History contains up to 50 pages. Saving the same page replaces its previous entry; older entries are removed when the limit is exceeded. You can clear history in the extension. Your language preference is also stored locally; clearing history does not reset it. Select Auto to follow your browser language. No cloud synchronization is used.

Uninstalling the extension removes its extension storage. Text you copy and JSON files you export remain under your control and are not deleted when you uninstall.

Information we do not use or transmit

The extension does not use cookies, login credentials, store administrator access, order or customer records, payment information or form input for its features. It contains no analytics, advertising, telemetry or remotely executed scripts. The detection feature does not send page information or results to the publisher or third-party servers. Data is not sold or used for advertising, creditworthiness or lending decisions.

Permissions

activeTab temporarily permits inspection of the page you choose to detect. scripting runs the bundled read-only collector in an isolated world. storage saves your language preference and manually saved results locally. No persistent all-sites host permission is requested, and the extension does not change website content.

External links and voluntary support requests

Opening an official theme listing or support link navigates to an external website, whose own policy applies. If you submit information through GitHub Issues, GitHub processes that submission under its policies. Do not include passwords, access tokens or customer information in support requests.

Security and detection limits

Local data relies on the protections of your device and Chrome configuration; the extension does not provide a separate encryption layer. Public metadata may be modified and third-party configuration may be outdated. A match does not prove licensing, an unmodified theme or access to private source code.

Limited Use

Still Theme Lens complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Information is used only for the disclosed platform and theme detection features, user-requested copying and export, local history and language preferences, not for unrelated purposes.

Contact and changes

For privacy questions or support, use GitHub Issues. This policy will be updated if data handling materially changes. Still Theme Lens is independent and is not affiliated with or endorsed by Shopify, WordPress, WooCommerce or Google.

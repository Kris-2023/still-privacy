Still — Privacy Policy

Updated November 26, 2026 · Covers Still 3.0.0 and earlier releases

Still — Quiet New Tab replaces the Chrome new tab page with a clock, search field, favorite links, backgrounds and a task workspace. This policy describes the extension's data handling.

Data stored and why

Your preferences, favorite website names and URLs, wallpaper URL and tasks are stored to provide the new tab features. Task records can include titles, lists, plan dates, deadlines, steps, completion state and Markdown notes. The workspace retains recoverable tasks and lists in its Trash.

Still saves task records on your device first. Small settings and eligible task records also use Chrome sync storage. Chrome may synchronize these data through your Google account when enabled and supported. Records that exceed Chrome’s storage limit remain on your device until they can be synced. The extension cannot verify delivery to another device.

Uploaded wallpaper images use chrome.storage.local and are not uploaded to Chrome sync by this extension. Pending task drafts use the extension's localStorage for recovery. A normal HTML preview uses browser-local storage instead of extension sync.

Network requests

Within Still, you can choose Google, Baidu, Bing, Yuanbao Search (so.qq.com), or Chrome default. New installations start with Google; existing supported search preferences are retained. Queries are sent to the selected service only when you submit a search. The Chrome default option uses chrome.search; other options open the selected provider's HTTPS search page. Still does not change your browser's default search settings. Explicit YouTube and GitHub site searches navigate to those sites with your query. Opening a favorite link or URL navigates to the selected website. Using an external wallpaper URL makes an image request to that host, which can receive ordinary request information such as your IP address. The privacy practices of Google, search providers, image hosts and visited websites govern their services.

Inter font files are bundled with the extension and loaded locally. No request to a font service is needed to display the interface.

Optional online wallpaper collection

Starting in 2.7.0, you can enable a curated public wallpaper collection. It is disabled by default. When enabled, Still downloads a validated JSON catalog, thumbnails and selected photos from kris-2023.github.io/still-privacy/wallpapers/, hosted by GitHub Pages. These requests omit credentials and referrers; GitHub may receive ordinary connection information such as your IP address. This is a public image download service, not private photo storage. No uploaded photos, tasks or settings are sent to this host. The catalog contains data only; executable code is bundled with the extension.

Wallpaper selection, public image descriptions, favorite IDs and daily rotation preferences use Chrome storage.sync. Full downloaded images use a local IndexedDB cache with a 32 MiB target limit. You can clear downloaded images in settings. Image files themselves are not synchronized; another device downloads the selected public image when online collection is enabled. Local uploaded images remain device-only. Disable online collection to stop new gallery requests. Search and user-supplied wallpaper URLs remain separate features.

Developer access and use

Still does not include a private user-data server, analytics, advertising, remote scripts, or background browsing-history collection. The extension does not send your tasks, settings or images to the developer. It does not sell personal data or use it for advertising, creditworthiness, or purposes unrelated to the new tab features.

Older notes and recovery

Earlier versions store Markdown lists as separate Chrome sync items and keep recovery drafts and bounded note history on the device. When upgrading to 3.0.0, Still converts existing lists into the workspace and retains a local copy of the original Markdown, pending drafts and available history. Copies retained for recovering conflicting task edits are stored on the device. You can export these records for recovery.

Backups and your control

You can edit tasks and favorite links, move tasks and lists to Trash, remove a local wallpaper, and export a JSON backup of settings and tasks. Backups are downloaded to the location chosen by your browser and may contain personal content you entered. Keep them private. Importing a backup is optional and replaces the settings and tasks after you review and apply it; a current-data backup is downloaded first.

Data remain in browser storage until you change or remove them or clear the relevant storage. Uninstalling can remove extension-local data; copies in Chrome account sync and downloaded backups follow their respective controls and must be managed separately. Disabling the extension alone does not delete its data.

Permissions

storage saves the data described above. search runs submitted web searches using your existing Chrome provider when the Chrome default option is selected. Still does not request access to browsing history, all websites, tabs, contacts, or account identity.

Support and changes

Publisher-provided support profile: Kris-2023 on GitHub. Contact options depend on those made available by the publisher on that profile. This policy should be updated if the extension's handling of data changes.

中文摘要

3.0.0 的工作区先把任务、清单、计划日期、截止日期、步骤及 Markdown 备注保存在本机。符合容量限制的任务记录会通过 Chrome 的同步存储保存，送达其他设备取决于 Chrome 同步状态。达到容量限制的内容暂留本机。升级会保留原 Markdown、待同步草稿及可用版本历史的本地副本，以便导出恢复。回收站保留可恢复的任务和清单。

Still 保存你输入的待办、常用网站和偏好设置，以实现新标签页功能。小型数据交给 Chrome 同步存储；本地上传的图片和待办恢复草稿保留在本机。搜索服务可选 Google、百度、Bing、元宝搜索（so.qq.com）或 Chrome 默认；新安装默认 Google，不更改浏览器默认搜索设置。主动提交的搜索与远程壁纸会分别向对应搜索服务及图片网站发出请求。字体随扩展本地加载，不请求远程字体服务。2.7.0 新增可选的在线精选图库，默认关闭。开启后会向 GitHub Pages 请求公共图片和清单，托管方可接收 IP 等普通连接信息；请求不附带凭据或来源页面。壁纸选择、收藏和轮换偏好使用 Chrome 同步，图片缓存在本机 IndexedDB（目标上限 32 MiB），可以手动清除。另一设备通过公开地址下载同一张图片，本地上传图片仍不上传、不跨设备同步。扩展不包含私有用户数据服务器、分析追踪、广告或远程脚本。备份文件由你自行保管，可能含有你输入的个人信息。

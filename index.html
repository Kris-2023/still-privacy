Still — Privacy Policy

Prepared September 17, 2026 · Version 2.2.0

Still — Quiet New Tab replaces the Chrome new tab page with a clock, search field, favorite links, backgrounds and a Markdown task list. This policy describes the extension's data handling.

Data stored and why

Your preferences, favorite website names and URLs, wallpaper URL, and Markdown tasks are stored to provide the features you request. Small settings and task documents use Chrome's storage.sync. Chrome may synchronize these data through your Google account when enabled and supported. With sync disabled, this storage can remain local. The extension cannot verify delivery to another device.

Uploaded wallpaper images use chrome.storage.local and are not uploaded to Chrome sync by this extension. Pending task drafts use the extension's localStorage for recovery. A normal HTML preview uses browser-local storage instead of extension sync.

Network requests

General search is submitted through chrome.search to your Chrome default search provider. Explicit YouTube and GitHub site searches navigate to those sites with your query. Opening a favorite link or URL navigates to the selected website. Using an external wallpaper URL makes an image request to that host, which can receive ordinary request information such as your IP address. The privacy practices of Google, search providers, image hosts and visited websites govern their services.

Developer access and use

Still does not include a developer-operated data server, analytics, advertising, remote scripts, or background browsing-history collection. The extension does not send your tasks, settings or images to the developer. It does not sell personal data or use it for advertising, creditworthiness, or purposes unrelated to the new tab features.

Backups and your control

You can edit or delete tasks and favorite links, remove a local wallpaper, and export tasks or a JSON settings backup. Backups are downloaded to the location chosen by your browser and may contain personal content you entered. Keep them private. Importing a backup is optional and replaces the settings and tasks after you review and apply it; a current-data backup is downloaded first.

Data remain in browser storage until you change or remove them or clear the relevant storage. Uninstalling can remove extension-local data; copies in Chrome account sync and downloaded backups follow their respective controls and must be managed separately. Disabling the extension alone does not delete its data.

Permissions

storage saves the data described above. search runs submitted web searches using your existing Chrome provider. Still does not request access to browsing history, all websites, tabs, contacts, or account identity.

Support and changes

Publisher-provided support profile: Kris-2023 on GitHub. Contact options depend on those made available by the publisher on that profile. This policy should be updated if the extension's handling of data changes.

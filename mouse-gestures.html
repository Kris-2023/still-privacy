网页访问与手势

扩展在普通 HTTP 和 HTTPS 网页中识别右键手势。它使用当前网站的主机名应用站点规则，检查手势起点是否在可编辑区域，并在按住右键时临时使用鼠标坐标识别手势和显示轨迹。设置页的录入与练习区也会临时处理鼠标坐标。

本地设置与删除

扩展使用 Chrome 的本机扩展存储保存你选择的站点规则、手势绑定、轨迹和动作提示偏好。站点规则包含主机名。手势绑定包含方向组合、对应动作和启用状态。原始鼠标坐标、练习轨迹、访问记录和已执行的手势不会写入长期存储。你可以在设置里更改规则和手势，卸载扩展会移除本机扩展存储。

数据传输

手势识别与设置处理在设备上完成。扩展不向开发者或第三方发送这些信息，也不使用账号、Cookie、分析统计或广告追踪。

有限使用与联系

本扩展仅为以上功能使用数据，遵守 Chrome 网上应用店用户数据政策及其有限使用要求。隐私问题和支持请求可通过 GitHub Issues 提出。

Still Mouse Gestures Privacy Policy

Version 0.2.1 · Updated November 13, 2026 · Published by Kris-2023

Website access and gestures

The extension recognizes right-button gestures on ordinary HTTP and HTTPS web pages. It uses the current hostname to apply site rules, checks whether a gesture begins in an editable area, and temporarily uses mouse coordinates to recognize a gesture and show its trail. The recording and practice areas also use mouse coordinates temporarily.

Local settings and deletion

The extension uses Chrome's local extension storage to keep your site rules, gesture bindings, and trail and action-hint preferences. Site rules include the hostname. Gesture bindings include a direction sequence, an action, and its enabled state. Raw mouse coordinates, practice strokes, visited-page logs, and executed gestures are not kept in persistent storage. You can change your rules and bindings in settings. Uninstalling the extension removes its local extension storage.

Data transfers

Gesture recognition and settings processing stay on your device. The extension does not send this information to the publisher or third parties and does not use accounts, cookies, analytics, or advertising trackers.

Limited Use and support

This extension uses information only for the features described above and complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. For privacy questions and support, use GitHub Issues.

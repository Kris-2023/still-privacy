本机处理和设置

扩展读取当前网页的背景与文字样式、主题标记和站点主机名，用于应用阅读配色和匹配站点规则。Chrome 的本机扩展存储保存外观偏好、站点规则和休息提醒的设置与调度状态。未保存的预览和临时暂停状态仅在浏览器会话中保留，包含相关标签页标识。扩展不使用 Chrome Sync，也不向发布者上传页面内容、访问记录或使用统计。

页面资源请求

在为网页调整配色时，扩展可能向网页引用的 HTTP 或 HTTPS 资源服务器请求样式表和图片。资源服务器会收到普通网络连接所需的 IP、资源 URL 和请求元信息。扩展自己的后台请求省略凭据和来源地址，并拒绝重定向。读取的资源可能短暂留在有大小和时限的内存缓存中。

权限和可选提醒

网站访问和脚本权限用于为网页配色，存储权限用于本机设置，闹钟权限用于调度提醒。通知和空闲检测权限为可选项，启用相应提醒功能时会请求授权。空闲检测只使用 Chrome 提供的活跃、闲置或锁定状态。

你的选择和删除

你可关闭扩展、设定网站保持原样、暂停标签页、关闭提醒或调整 Chrome 扩展权限。将网站改为跟随全局设置会删除其独立规则。卸载扩展会移除本机扩展存储。

有限使用与联系

本扩展仅为以上功能使用数据，遵守 Chrome 网上应用店用户数据政策及其有限使用要求。隐私问题和支持请求可通过 GitHub Issues 提出。

Still Comfort Privacy Policy

Version 0.2.1 · Updated November 13, 2026 · Published by Kris-2023

On-device processing and settings

The extension reads a page's background and text styles, theme indicators, and hostname to apply a reading palette and match site rules. Chrome's local extension storage keeps appearance preferences, site rules, and break reminder settings and scheduling state. Unsaved previews and temporary pauses remain in browser session storage with the related tab identifiers. The extension does not use Chrome Sync or send page content, browsing logs, or usage statistics to the publisher.

Page resource requests

While recoloring a page, the extension may request stylesheets and images referenced by that page from their HTTP or HTTPS servers. Those servers receive standard connection information such as an IP address, the resource URL, and request metadata. The extension's background requests omit credentials and referrers and reject redirects. Resources may be kept briefly in a size-limited in-memory cache.

Permissions and optional reminders

Website and scripting access lets the extension recolor pages, storage keeps settings locally, and alarms schedule reminders. Notification and idle permissions are optional and requested when you enable the related reminder feature. Idle detection uses only Chrome's active, idle, or locked status.

Your choices and deletion

You can turn off the extension, keep a site's appearance unchanged, pause a tab, disable reminders, or adjust Chrome extension permissions. Returning a site to the global default deletes its rule. Uninstalling the extension removes its local extension storage.

Limited Use and support

This extension uses information only for the features described above and complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. For privacy questions and support, use GitHub Issues.

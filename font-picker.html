本机网页字体选择器 · 隐私政策

适用版本 1.0.2 · 更新于 2026-11-13 · 发布者 Kris-2023

网页访问

扩展在网页及可访问的嵌入框架中检查元素是否需要应用或排除字体样式。它不保存网页正文、表单内容或访问记录。扩展没有开发者运营的服务、账号系统、广告追踪或分析统计。

本机字体与同步设置

只有点击「读取本机字体」且 Chrome 允许访问时，扩展才读取已安装字体的家族名称。字体列表用于当前设置面板，扩展不保存完整列表或字体文件。本机字体读取仅支持提供该接口的安全顶层网页。接口不可用时，你仍可用预设或手动输入名称。应用字体后，网站脚本可以读到应用于网页的字体样式。你保存的字体名称和启用状态使用 Chrome 的同步存储，并可能按你的 Chrome 同步设置在设备之间同步。

网络字体

预览或应用预设网络字体时，浏览器会向 Google Fonts 或 jsDelivr 请求样式表与字体资源。服务商会收到加载资源所需的连接信息，例如 IP 地址和请求的资源 URL。根据网页的来源策略，请求也可能带来源信息。服务商的处理适用各自的隐私政策。

控制与删除

你可选择本机字体、关闭替换或撤销站点的本机字体访问权限。扩展可以在 Chrome 中移除，同步数据由 Chrome 的同步设置管理。

有限使用与联系

本扩展仅为以上功能使用数据，遵守 Chrome 网上应用店用户数据政策及其有限使用要求。隐私问题和支持请求可通过 GitHub Issues 提出。

Local Web Font Picker Privacy Policy

Version 1.0.2 · Updated November 13, 2026 · Published by Kris-2023

Website access

The extension checks elements on web pages and accessible embedded frames to apply font styles or skip excluded elements. It does not save page text, form contents, or browsing logs. It has no publisher-operated backend, account system, advertising trackers, or analytics.

Local fonts and synced settings

The extension reads installed font family names only after you choose to read local fonts and Chrome allows access. It uses the list in the settings panel and does not save the complete list or font files. Local font access works on secure top-level pages where the browser provides the interface to the extension. If the interface is unavailable, you can use a preset or type a font family. Scripts on the page can inspect the font styles applied to that page. Chrome sync storage keeps your saved font family and enabled state, which may sync between devices according to your Chrome settings.

Online fonts

Previewing or applying a preset online font causes the browser to request stylesheets and fonts from Google Fonts or jsDelivr. The providers receive ordinary connection information, such as the IP address and requested resource URL. A referrer may also be included depending on the page's policy. The providers handle those requests under their respective privacy policies.

Controls and deletion

You can choose a local font, turn off font replacement, or revoke a site's local font access. You can remove the extension from Chrome and manage synced data in Chrome's sync settings.

Limited Use and support

This extension uses information only for the features described above and complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. For privacy questions and support, use GitHub Issues.
